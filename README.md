# projeto-avaliativo-m12-BookingFlow
Gerenciamento de reservas de hotel

## Automações de Fluxo

Este projeto utiliza skills do Kiro para automatizar o fluxo de desenvolvimento:

- **start-issue** — inicia uma issue criando a branch correta e movendo o card para "Em Andamento" no GitHub Projects
- **finish-issue** — encerra a demanda revisando a documentação, commitando e abrindo o PR automaticamente
- **registrar-prompt (hook)** — registra automaticamente prompts relevantes em `docs/prompts.md`

### Documentação viva

- `docs/prompts.md` — histórico de prompts utilizados nas interações com IA
- `docs/prompt-improvement.md` — registro de refinamentos e melhorias de prompts
